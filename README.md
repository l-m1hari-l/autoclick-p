# autoclick-p
# a simple console autoclicker 
a simple autoclicker made with pascalabc.net 

to send keys it uses 

```C# 
Sendkeys.Sendwait
```
method, so keys that cannot be sent with this method, also cant be sent with this autoclicker

#### Letter keys, number keys and symbol keys (for example "*") are supported, but other keys(like Print Screen or Alt) aren't. Except for Enter key (write a \ to use it) and Escape key (write ] to use it)
others are going to be added later
